# Plan de implementación

Cada etapa termina con: `npm run typecheck` ✅ · `npm test` ✅ · bundle Android ✅ · prueba en el teléfono.

| Etapa | Contenido | Estado |
|---|---|---|
| 1 — Fundamentos | Expo + TS + Router, tema, 5 tabs, componentes UI, curva de niveles + tests | ✅ Validada en dispositivo |
| 2 — Persistencia | Cliente SQLite, migración v1 (esquema completo), transacciones anidables, repositorios (perfil, ajustes, objetivos, mediciones), Zod, onboarding con importación histórica, 30 tests contra SQLite real | ✅ Lista para validar |
| 3 — Entrenamiento | Catálogo de ejercicios base (según tu equipo), rutinas, plan semanal 3/4 días, sesión en vivo, series rápidas, historial, récords | ⏳ |
| 4 — Nutrición e hidratación | Alimentos propios y favoritos, registro por gramos o porciones, macros con snapshot, agua con un toque, objetivos | ⏳ |
| 5 — RPG | Servicio de XP idempotente, topes, misiones diarias y semanales con evaluación automática, rachas, stats | ⏳ |
| 6 — Progreso | Mediciones, fotos privadas, gráficos SVG, comparar períodos, import/export JSON con vista previa | ⏳ |
| 7 — Distribución | QA, accesibilidad, `eas build` APK, documentación final | ⏳ |
